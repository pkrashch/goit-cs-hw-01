# goit-cs-hw-01

Домашнє завдання до модуля «Архітектура комп'ютерів».

## Завдання 1 — Асемблер

Програма на асемблері (NASM) обчислює вираз `b - c + a`, де `a = 5`, `b = 3`, `c = 2`.

Файл: `task1/calc.asm`

Компіляція та запуск (DOSBox):
```
nasm -f bin -o calc.com calc.asm
mount c f:\path\to\folder
c:
calc.com
```

Результат: `Result: 6`

## Завдання 2 — Інтерпретатор арифметичних виразів

Розширений інтерпретатор (Python) з конспекту: додано підтримку множення (`*`), ділення (`/`) та виразів у дужках `( )`.

Файл: `task2/interpreter.py`

Запуск:
```
python3 interpreter.py
```

Приклад:
```
Введіть вираз (або "exit" для виходу): (2 + 3) * 4
20
```
